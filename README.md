# LAMZU Thorn V2 Battery Monitor

LAMZU Thorn V2（LAMZU 8K Dongle V2 接続）のバッテリー残量をWindows上で常駐監視するための軽量システムトレイアプリケーションです。

公式Webドライバーを常時開くことなく、USB HID通信から直接バッテリー残量・充電状態・DPI・ポーリングレートを取得し、タスクトレイおよびステータスパネルにリアルタイムで表示します。

---

## 主な機能

1. **バッテリー残量の常駐監視**
   - タスクトレイアイコンに残量をリアルタイム表示（16x16px〜32x32pxの高DPI対応）。
   - マウスカーソルを合わせるとツールチップで詳細（残量、スリープ推測、ドングル状態）を表示。
2. **3種類のアイコンデザイン**
   - 右クリックメニューの「アイコンデザイン」から即時切り替え可能。
     - **数字+バッテリー表示**（デフォルト：上部に数値、下部にバッテリーゲージ）
     - **数字のみ**（バッテリー枠なし、数値を最大化して表示）
     - **バッテリーのみ**（数値なし、横長ゲージのみで表示）
   - 残量に応じた統一カラー（緑：51〜100%、橙：21〜50%、赤：0〜20%、灰：未取得）。
3. **左クリックで開くステータスパネル**
   - トレイアイコンを左クリックすると、画面端にTkinter＋Canvas製のダークテーマパネルを表示。
   - 大きなバッテリー残量表示、横長バッテリーゲージ、および接続ステータス。
   - **充電中⚡アイコン**：HIDパケットから取得した充電ステータス（Byte 3 == 0x04 等）に基づいて、充電中と判定された場合のみ残量横にゴールドの⚡アイコンを表示。
   - **現在のDPI / ポーリングレート**：パネル表示時にバックグラウンドで安全に問い合わせを行い、3点ドットアニメーションを経て左右2列のカードに現在値を表示。
4. **低バッテリー通知（トースト通知）**
   - バッテリー残量20%以下（低残量警告）および10%以下（緊急警告）でWindowsトースト通知を発報。
   - 充電回復後の自動再アーム、重複通知防止、およびメニューからのテスト通知機能を搭載。
5. **Windows自動起動対応**
   - 右クリックメニューから「Windows起動時に自動起動」の有効/無効をワンクリックで切り替え可能（管理者権限不要。設定はHKCU Runレジストリに登録され、config.jsonには保存されません）。
6. **公式Webドライバー連携**
   - 右クリックメニューから「LAMZU Auroraを開く」を選択すると、既定のブラウザーで公式Webドライバー（LAMZU Aurora）を直接起動。
7. **設定の永続化と安全性**
   - 選択したアイコンデザイン、通知設定をローカル設定ファイル (config.json) にアトミック保存（自動起動はHKCU Runレジストリで管理）。
   - Windows Named Mutexによる二重起動防止機能を内蔵。

## 動作環境・対象デバイス

- **対応OS**: Windows 11 (64-bit 実機動作確認済み) / Windows 10 (64-bit 未検証・互換動作想定)
- **対象デバイス**: LAMZU Thorn V2（LAMZU 8K Dongle V2 経由での接続）
  - Vendor ID (VID): `0x37B0`
  - Product ID (PID): `0x002E`
- **Python環境**（ソースコードから実行・開発する場合）:
  - Python 3.11 以上（Python 3.13 動作確認済み）

## 使用方法

### 1. 配布用EXE（単一実行ファイル）から起動する場合

1. `LAMZU-Thorn-Battery-Monitor.exe` を任意のフォルダーに配置して実行します。
2. コンソール画面は表示されず、タスクバー右下の通知領域（システムトレイ）にアイコンが常駐します。
3. トレイアイコンを**左クリック**するとステータスパネルが表示され、**右クリック**すると各種設定メニューが表示されます。

### 2. Pythonソースコードから実行する場合

#### 依存ライブラリのインストール
```powershell
pip install -r requirements.txt
```

#### アプリケーションの起動
```powershell
# 通常の実機監視モード
python app.py

# 実機なしで動作を確認できるデモモード（シミュレーション）
python app.py --demo

# 詳細ログを出力するデバッグモード
python app.py --debug
```

#### CLIツールによるHID通信診断
```powershell
# 接続されているLAMZU HIDデバイスを一覧表示
python probe_hid.py --list

# 受信パケットのリアルタイム監視
python probe_hid.py --read --seconds 30
```

## ソースコードからのOneFile EXEビルド方法

PyInstallerを使用して、外部依存のない単一の実行可能ファイル（`.exe`）をビルドできます。

```powershell
# PyInstallerのインストール
pip install pyinstaller

# Specファイルを使用したビルド
pyinstaller --noconfirm LAMZU-Thorn-Battery-Monitor.spec
```

ビルドが完了すると、`dist/LAMZU-Thorn-Battery-Monitor.exe` に単一の実行可能ファイルが生成されます。

## 設定ファイルおよびログの保存場所

ユーザー設定および実行ログは、Windowsのユーザー個別データ領域に自動生成・保存されます。

- **設定ファイル**:
  `%LOCALAPPDATA%\LAMZUThornBatteryMonitor\config.json`
  （アイコンデザインおよび通知設定などのアプリケーション設定）
- **Windows自動起動設定**:
  レジストリ `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`（値名: `LAMZUThornBatteryMonitor`）
  ※自動起動設定はWindowsレジストリに登録され、`config.json` には保存されません。
- **ログファイル**:
  `%LOCALAPPDATA%\LAMZUThornBatteryMonitor\logs\app.log`
  （最大1MB × 3世代の自動ローテーション）

1. **非公式ソフトウェアについて**
   - 本ツールは個人有志が作成した非公式のオープンソースソフトウェアです。LAMZU社およびその関連企業とは一切関係ありません。
2. **読み取り専用設計の厳守**
   - 本アプリケーションはマウスのファームウェア書き換えやDPI・ポーリングレートの変更操作を一切行いません（変更は公式のLAMZU Auroraで行ってください）。
3. **USB充電ケーブル取り外し直後の表示**
   - マウスのUSB給電ケーブルを取り外した直後、マウスを全く動かさずに静止させた場合、ドングル側が一時的に以前の充電ステータス（`0x04`）を保持することがあります。マウスを動かすかクリックすると直ちにマウス本体から最新のパケットが送信され、非充電状態に復帰します。
4. **長時間連続運用の検証**
   - 数時間〜数日間にわたる長時間の連続稼働テストや、バッテリー満充電（100%）完了時の長期遷移テストは未実施です。
